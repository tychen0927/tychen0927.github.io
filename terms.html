Personal use

“History Reopened & Made in Context Channel API” is a personal desktop utility for its owner to call the YouTube Data API for the owner's channels. It is not offered as a public multi-user service. Do not use it to authorize a Google Account or channel you do not control.

Authorization and scope

The client requests https://www.googleapis.com/auth/youtube.force-ssl, which can permit viewing, editing, and permanently deleting YouTube videos, ratings, comments, and captions. The owner must select the intended channel identity and check the target and requested API operation before any write. A token holder may have broader access than a metadata-only update.

Google's OAuth and YouTube API services are governed by their applicable terms, including the Google API Services User Data Policy and YouTube API Services Terms of Service.

Availability and credentials

Access may stop if Google expires, revokes, invalidates, or restricts a credential or the API access. Refresh tokens are not guaranteed to remain valid forever. Keep them private and remove them when no longer needed.
