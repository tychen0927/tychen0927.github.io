Privacy Policy

Effective date: 2026-10-06.

Who operates this utility

This is a personal desktop OAuth utility operated by the owner of the History Reopened and Made in Context YouTube channels. It is not a public multi-user service. For support, use the developer support email shown on the Google consent screen.

Google data accessed and purpose

The app requests https://www.googleapis.com/auth/youtube.force-ssl. Google describes this scope as allowing access to YouTube videos, ratings, comments, and captions, including editing and permanent deletion. The owner uses it only for YouTube API operations the owner requests. The setup check used channels.list(mine=true) and read channel IDs and titles to verify the selected channel. The scope is broad and the client itself does not technically restrict consent to the two intended channels.

Transmission and storage

The owner authorizes access through Google's OAuth flow. The local helper exchanges the authorization code with Google's token service and sends authorized requests to the YouTube Data API. Google receives the requests needed to provide OAuth and YouTube services.

The owner stores the desktop client configuration and per-channel refresh tokens in a protected local configuration directory. Short-lived access tokens are held in process memory by the helper and are not written to the credential file. If the owner copies credentials to a private Codex Cloud environment, those values are processed there for tasks that request them and are supplied as environment variables rather than committed to source control. Any cloud copy is subject to that environment's security, access, and retention controls.

The utility has no separate advertising, analytics, or data-broker integration in its current workflow. Visitors to this documentation site are served by GitHub Pages; GitHub says it logs visitor IP addresses for security purposes. This website itself has no tracking scripts or contact form.

Retention, security, and choices

Refresh tokens remain in the owner's protected credential store until the owner removes them or revokes consent. Google may invalidate tokens. The owner can revoke access in Google Account third-party access settings and should remove local or cloud copies when they are no longer needed. Do not share or publish refresh tokens.

The owner will update this policy if access, use, storage, sharing, or intended users change. The app must not use Google user data beyond the practices described here and must follow Google's API Services User Data Policy and the YouTube API Services Terms of Service.
