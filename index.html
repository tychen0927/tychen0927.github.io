History Reopened & Made in Context Channel API

This site describes a personal desktop OAuth utility used by its owner to make owner-requested YouTube Data API calls for the History Reopened and Made in Context YouTube channels. It is documentation for the owner's local API workflow, not a public multi-user service.

What the utility does

The owner authorizes a Google account and selects the relevant YouTube channel identity. The local workflow can request the YouTube Data API scope https://www.googleapis.com/auth/youtube.force-ssl. That scope is broad: it may allow viewing, editing, or permanently deleting YouTube videos, ratings, comments, and captions. The owner should authorize only an account and channel they control and should confirm each target and operation before making API writes.

The client is configured as an External OAuth app. If published in Google Auth Platform, other Google Accounts may be able to request consent; this configuration does not technically limit the client to these two channel identities. The utility is intended for its owner's personal use and is not offered as a public upload service.

Data and credentials

Google receives OAuth requests and the YouTube API requests needed to provide its services. OAuth client configuration and refresh tokens are kept by the owner in protected local files. If the owner imports them into a private Codex Cloud environment, they are processed in that environment for the owner's requested work. They must never be committed to a public repository.
